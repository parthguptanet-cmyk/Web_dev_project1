 Web Dev Project 1 :-

A front-end recreation of the award-winning Cynthia Ugwu portfolio website, built to strengthen my skills in modern web development. This project focuses on creating a smooth, interactive, and visually appealing user experience using HTML, CSS, and JavaScript.

Features :-

* Responsive and modern UI design
* Smooth scrolling effects using Locomotive Scroll
* Engaging animations powered by GSAP (GreenSock Animation Platform)
* Custom mouse follower interaction
* Scroll-triggered animations and transitions
* Clean and structured code organization
* Improved understanding of DOM manipulation and event handling

 Technologies Used :-

* HTML5
* CSS3
* JavaScript (ES6)
* GSAP
* Locomotive Scroll

Learning Outcomes :-

Through this project, I gained hands-on experience with advanced front-end animations, smooth scrolling techniques, interactive cursor effects, and creating immersive user experiences inspired by modern portfolio websites.
